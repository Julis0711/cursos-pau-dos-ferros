# Site dos Cursos - IFRN Campus Pau dos Ferros

Site em React com navegação por React Router, apresentando os cursos técnicos do
Campus Pau dos Ferros.

## Páginas

- `/` - Início (IFRN e Campus Pau dos Ferros)
- `/informatica` - Técnico em Informática
- `/alimentos` - Técnico em Alimentos
- `/apicultura` - Técnico em Apicultura
- Qualquer outro endereço - Página não encontrada

## Como executar

```bash
npm install
npm run dev
```
